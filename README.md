# AI for Good - ESG Report Generation Landing Page

一个专注于ESG报告生成的现代化落地页。

## 如何查看网站

### 方法一：使用 GitHub Pages（推荐）

1. 访问你的 GitHub 仓库：`https://github.com/luckyswallow/Claude-Hack`
2. 点击 **Settings**（设置）
3. 在左侧菜单找到 **Pages**
4. 在 **Branch** 下拉菜单中选择 `claude/create-website-01MLkEjAA6RaGuGBnSTyVX7C`
5. 点击 **Save**（保存）
6. 等待几分钟，GitHub 会给你一个网址，类似：
   `https://luckyswallow.github.io/Claude-Hack/`

### 方法二：下载到本地查看

1. 在 GitHub 上找到你的分支：`claude/create-website-01MLkEjAA6RaGuGBnSTyVX7C`
2. 点击绿色的 **Code** 按钮，选择 **Download ZIP**
3. 解压 ZIP 文件到你的电脑
4. 找到 `index.html` 文件
5. 双击 `index.html`，用浏览器打开

或者使用 Git 克隆：
```bash
git clone https://github.com/luckyswallow/Claude-Hack.git
cd Claude-Hack
git checkout claude/create-website-01MLkEjAA6RaGuGBnSTyVX7C
```

然后直接双击 `index.html` 或用浏览器打开。

### 方法三：本地运行服务器

如果你的电脑上有 Python：
```bash
cd /path/to/Claude-Hack
python3 -m http.server 8000
```
然后在浏览器访问：`http://localhost:8000`
