🌱 AI for Good – ESG Report Generation Landing Page

A modern, lightweight landing page designed to showcase an AI-powered ESG (Environmental, Social, and Governance) report generation solution.

🌐 How to View the Website
Option 1: GitHub Pages (Recommended)
Go to your repository:
👉 https://github.com/luckyswallow/Claude-Hack
Click Settings
In the left sidebar, select Pages
Under Branch, choose:
claude/create-website-01MLkEjAA6RaGuGBnSTyVX7C
Click Save
Wait a few minutes. GitHub will generate a URL like:
https://luckyswallow.github.io/Claude-Hack/

Option 2: Download and Open Locally
Navigate to the branch:
claude/create-website-01MLkEjAA6RaGuGBnSTyVX7C
Click the green Code button → Download ZIP
Extract the ZIP file
Locate:
index.html
Double-click to open in your browser

Option 3: Clone with Git
git clone https://github.com/luckyswallow/Claude-Hack.git
cd Claude-Hack
git checkout claude/create-website-01MLkEjAA6RaGuGBnSTyVX7C

Then open:

index.html
Option 4: Run a Local Server

If you have Python installed:

cd /path/to/Claude-Hack
python3 -m http.server 8000

Open in browser:

http://localhost:8000
